Вызов функции с параметром n: sum_to(n). Формула суммы: S = n(n + 1) / 2.

Пример запуска в REPL: sum_to(5)
Ожидаемый результат: 15

Копирование строки: нажмите Ctrl + C (Windows/Linux) или Cmd + C (macOS).

Блочный листинг

def sum_to(n):
    # сумма от 1 до n включительно
    return n * (n + 1) // 2

print(sum_to(5))  # 15

Вывод программы: 15

Запуск: выделите блок и нажмите Ctrl + C, затем вставьте в REPL Ctrl + V.
